# M1.5 — Expo istemci iskeleti (mobil + web)

## Amaç
Expo istemci iskeleti: ebeveyn ve çocuk için ilk uçtan uca akış (mobil + web)

## Okunacak bölümler
- docs/sections/05-urun-gereksinimleri.md
- docs/sections/09-api-tasarimi.md
- docs/sections/10-guvenlik-uyum.md

## Yapılacaklar
- Expo + Expo Router + TypeScript iskeleti, ESLint, Jest
- OpenAPI'den tipli API istemcisi
- Ebeveyn: kayıt, giriş, çocuk listesi, rıza onayıyla çocuk ekleme, eşleştirme bağlantısı
- Çocuk: bağlantıyla eşleşme, takma adla karşılama
- Backend: CORS, çocuk listesi ucu, OpenAPI dışa aktarma
- CI'da istemci job'ı

## Kabul kriteri
- Ebeveyn kayıt → çocuk ekleme → eşleştirme → çocuk modu akışı web'de ve Expo Go'da çalışır; lint, tip kontrolü, testler ve CI yeşil
